# My Personal Portfolio Website

## About the Project
This is my personal portfolio website, created to showcase my profile, education, technical skills, and projects.

## Technologies Used
- HTML
- CSS
- JavaScript
- Firebase / Firestore
- Git and GitHub
- Docker
- AWS
- GitHub Actions (CI/CD)

## Features
- Professional portfolio design
- About Me section
- Education and technical skills
- Profile photo
- Resume PDF
- Contact form connected to Firebase
